Entry for [The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun.

One funny line, one sentence, well under 200 characters: a phone dies at 2% right
as its owner is about to text "I'm almost there" — and the punchline is that the
text was a lie anyway. Two everyday truths (a dying battery, the "almost there"
fib) collide in a single surprise at the very last word.

## How to run

```sh
node main.ts
```

This writes the line to `/output/entry.txt`. Deterministic, no network, no input files.
